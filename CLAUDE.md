## Daily Sync Workflow

```bash
# Before starting: pull latest
git pull origin main

# After completing work
git add -A
git commit -m "<brief description>"
git push origin main
```

---

## Git Policy

- **Never** stage or commit anything under `data/`.
- **Never** commit files larger than 50 MB.
- Only commit: `.py`, `.do`, `.md`, `.tex`, `.r`, `.ado`.
- Results tables (`.tex` under `results/`) may be committed.

---

## Code Index Files

Each code subdirectory may contain a `CODE_INDEX.md` generated by `/project:code-scan`.
Run `/project:code-scan <directory>` after adding or substantially changing scripts.

## Before Editing Scripts

Check if a `CODE_INDEX.md` exists in the target directory; read it for context.
Update `## Progress Log` in `PROJECT.md` at the end of each session.
